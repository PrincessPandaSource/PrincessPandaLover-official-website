× About the Game

This is a Javascript game practice by PrincessPandaLover, based on both Sega's Sonic the Hedgehog series and RNG games on Roblox like Sol's RNG.

Yes, the chances are deliberately weighted so that you have to wait a long time for some characters. This is an RNG game, after all. (Fortunately, the weights are not as extreme as Sol's RNG's.)

(This game does not provide any method of notifying of rolling an elusive character, so check your inventory regularly!)

Character images are copyrighted by Sega. Character descriptions were copied from Sonic Wiki Zone and are licensed under CC-BY-SA.

Icons are in public domain.
